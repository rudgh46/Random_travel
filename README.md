# 오늘의 랜덤 여행 🚌

서울고속버스터미널(경부·영동선)에서 출발하는 랜덤 여행지를 뽑아주는 웹사이트입니다.
권역·예산·소요시간을 고르고 **출발!** 을 누르면 안내판이 돌아가다 목적지에서 멈추고,
탑승권 카드에 예상 요금·소요시간·등급·당일치기 여부를 보여줍니다.

## 실행

`Random_Travel.html`을 브라우저로 열기만 하면 됩니다. 별도 빌드·의존성 없음.

## 데이터

경부·영동선 실제 노선의 우등/일반 편도 요금·소요시간(약 40개 노선) 기준.
센트럴시티(호남선) 노선은 별도 터미널이라 미포함. 실제 출발편·잔여석은 코버스에서 확인하세요.
